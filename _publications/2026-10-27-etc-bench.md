Formulated evaluation-side transcript canonicalization (ETC), which maps multiple surface transcript forms to a single canonical form when their differences are not determined by the speech signal. Built ETC-Bench, the first and most comprehensive multilingual benchmark for ETC, covering 181 phenomenon types across 12 languages, where each instance is a minimal pair sharing a sentence context and differing only in a target span.

**Key Contributions:**
(1) Formulated the ETC task and constructed the multilingual benchmark covering 181 phenomenon types across 12 languages;
(2) Proposed Semantic-preserving Exact-match Normalization Accuracy (SENA), which combines exact agreement between independently canonicalized pair members with a pair-relative BERTScore constraint;
(3) Introduced the Taxonomy-guided Agent Canonicalization Skill (TACS), with which LLM agents outperform baseline systems on shared languages.
